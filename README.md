# Blog Brawl Stars

## Objetivo

Criar um blog simples sobre o jogo Brawl Stars usando HTML, CSS e JavaScript.

## Tecnologias usadas

- HTML
- CSS
- JavaScript

## Como usar

1. Abra o arquivo `index.html`.
2. Leia os posts do blog.
3. Assista ao vídeo.
4. Clique nos botões de coração e joinha.

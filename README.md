# Blog Brawl Stars

## Objetivo

Criar um blog simples sobre o jogo Brawl Stars usando HTML, CSS e JavaScript.

## Tecnologias usadas

- HTML
- CSS
- JavaScript

## Como usar

Abra o arquivo `index.html`, leia os posts, assista ao vídeo e clique nos botões de coração e joinha.
